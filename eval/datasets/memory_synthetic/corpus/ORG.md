# Org

Who does what. One owner per zone.

| Agent | Strong at | Zone |
|---|---|---|
| `planner` | plans, task packets, curation | plan and canon |
| `coder` | code, tests, repositories | code |
| `scout` | primary-source research, Russian-language sources | research |
| `herald` | outreach with a sent-check, follow-ups, CRM notes | revenue |
| `critic` | independent review | review |

## Routing

1. A script before a cheap model, a cheap model before an expensive one.
2. One GPU job at a time on the workstation.
3. A hand-back is at most 8 lines plus links.
4. One `herald` call loads about 25k tokens of context before the task, so small tasks go to it in batches.
